## How to add a new entry

1. When publishing a feature that uses a new image, add a section under the feature slug with the details above.
2. Before publish, verify: file path, source URL, license type verifiabile, attribution copy correct.
3. If permission granted by rights holder (photographer, label), log: name, method of confirmation, date.
4. Never publish an asset without a corresponding entry here.

## Rules of thumb

- **Wikimedia CC-BY / CC-BY-SA**: OK, always include Wikimedia link + license line.
- **Bandcamp / Apple Music album cover** (small thumbnail, review context): editorial fair use. Log source, no permission required.
- **Photographer press shot with explicit permission**: OK, log photographer + how permission was obtained.
- **Random Instagram / stock image without permission**: never.
- **AI-generated hero images**: allowed but must be logged as "AI-generated, [tool used]". Prefer real images.
